# 还原报告

`DeepSeek Harness Launcher.exe` 由 **PyInstaller onefile + Python 3.14 + tkinter** 打包。
本仓库 `src/` 内 10 个模块即由该 exe 内嵌字节码反编译并手工还原（语义等价，非逐字原文：
字节码不含注释与源码行号，还原时保留了 docstring 与可恢复的中文界面文案）。

## 还原方法

1. **解包**：pyinstxtractor 解出 PyInstaller CArchive（入口 `main.pyc`、8 个业务模块、PYZ 内其余代码）。
2. **反编译**：Python 3.14 无现成反编译器，因此：
   - 下载 zrax/pycdc 源码并用 Zig 在 Windows 上编译；
   - 基于本地 Python 3.14.7 的 `opcode/dis` 生成真正的 3.14 指令表
     （`tools/pycdc314/python_3_14.cpp` + `gen314map.py`），并补充
     `pyc_module.h` 的 3.14 magic 与 `bytecode.cpp` 的版本分支（详见该目录 README）。
3. **核对**：对每个模块，用 `marshal`+`dis` 逐代码对象比对；关键模块与原始 pyc 做
   **差分行为测试**（同一输入下输出/副作用逐项相等），`ui_main.py` 达到指令级一致。
   过程中修正了自动反编译的若干处语义反转（如 `core_backup._rebuild_deps` 守卫极性、
   `list_backups` 回退赋值顺序、`ui_main._icon_path` 返回值等）。

## 模块还原质量

| 模块 | 还原方式 | 验证 |
|---|---|---|
| paths / core_runner | 手工还原 | 隔离回归（smoke_core.py） |
| core_versions | 逐字节码转写 | 与原 pyc 差分行为测试（约 50 用例） |
| core_backup / core_plugins | 逐字节码转写 | 差分行为测试（robocopy/overlay 等） |
| core_launch | 手工还原 + 修复集成 | 隔离回归 + 修复路径实测 |
| ui_main | 逐字节码转写 | 指令级比对（71 个代码对象零差异） |
| ui_dialogs | 逐字节码转写 | 函数清单一致 + Tk 构件冒烟 |
| fix_links | 新增修复模块 | 迁移副本实测（见 README） |

## 两项工程修复

详见根 README：`fix_links.py`（跨机搬迁 junction 镜像自愈）与
`core_versions` 体积缓存（列表刷新不再全量递归统计）。
