# 架构与模块说明

## 运行时目录约定（全部相对启动器所在目录）

```
<启动器目录>\
├─ DeepSeek Harness Launcher.exe
└─ runtime\
   ├─ config.json          全局配置（registry/port/keep/tools…，无绝对路径）
   ├─ tools\              捆绑便携工具：node / pnpm
   ├─ npm-cache\           隔离的 npm 下载缓存
   ├─ logs\                版本启动日志
   ├─ backups\             全局备份根（可被 config.backup_root 覆盖）
   ├─ overlays\            插件禁用 overlay（*.patch.yml）
   ├─ .dsh\                默认 dsh 数据底座（无显式 DSH_HOME 时）
   └─ versions\<版本>\
      ├─ package\          dsh 内核 npm 安装区（node_modules/@deepseek-ai/dsh）
      ├─ home\             该版本数据目录（注入 DSH_HOME）
      └─ meta.json         该版本记录（cli/data/port/keep/install_mode…）
```

## 数据流

```
双击 exe → main.py（单实例锁）
  └─ ui_main.MainApp ── 事件经 core_runner.Bus（queue + 主线程 after 泵）
       ├─ core_versions   下载/安装/导入/删除/列表（npm）
       ├─ core_launch     启动/停止/健康检查（node <pkg>/lib/bin.js web）
       │    └─ fix_links  ★启动前自动修复 dsh junction 镜像（跨机搬迁）
       ├─ core_backup     快照备份/恢复（robocopy）
       └─ core_plugins    web profile 插件增删与禁用 overlay
```

## 关键设计

- **路径唯一源**：`paths.py`；存储一律“相对 runtime”，跨机搬迁后自动按新位置解析。
- **local 内核按当前位置解析**：`meta.cli` 残留的旧绝对路径会被忽略/归一化
  （`paths.version_cli` / `rewrite_cli_relative`）。
- **子进程环境**：启动 dsh 前把 `runtime\tools\node`（/pnpm）前置到 PATH，
  npm 缓存固定到 `runtime\npm-cache`，无需系统 Node。
- **进程归属安全**：停止/运行检测只认 meta 与版本目录锚点，绝不 `taskkill /im node.exe`
  全杀（见 `core_launch` 顶部说明）。
- **UI 并发模型**：耗时任务一律 `bus.run` 后台线程 + 主线程泵回收结果，
  单处理器异常不拖垮泵（`core_runner.Bus`）。
